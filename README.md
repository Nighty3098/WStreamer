Android MJPEG camera streaming app. Broadcasts your device camera over HTTP to any browser on the local network.

**Features:** front/back camera switch, pinch-to-zoom, resolution picker, frame rotation (0/90/180/270°), Material You UI.

Open `http://<device-ip>:<port>/video` in any browser to view the stream.
